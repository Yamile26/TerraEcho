# A two-minute TerraEcho demonstration

## 0:00–0:25 · Listen before explaining

Open the explorer, select 2026, week 40 (October 1), and choose a region with observations. Start sound. Explain the idea in one sentence: **“TerraEcho makes unusual satellite fire activity perceptible through sound, so exploring Earth does not depend on sight alone.”**

The general view is labeled as a bounding-box study area. Use a department selection when telling a specifically regional story. Never describe the 9,058 bounding-box detections as 9,058 individual Peruvian wildfires.

## 0:25–0:55 · Make the mapping understandable

Use the timeline to select another week and compare the audible result. Explain: latitude controls pitch, longitude controls stereo, FRP controls intensity and anomaly controls dissonance. Open the method dialog if needed. “Within usual activity” is a historical comparison, not a guarantee of healthy vegetation.

Show week 44 of 2026: the incomplete record produces silence and an explicit “insufficient data” label. This is a useful distinction between a calm observation and an unknown situation.

## 0:55–1:25 · Address the EIC challenge directly

Open **Estudio EIC**, play the NASA GEOS Aerosols frame and follow the scanning line. Toggle layers to isolate their voices. Explain that this sonifies visual features in an actual EIC visualization; it does not measure aerosol concentration or assert a causal link with the selected Peru fires. Its date is shown separately.

## 1:25–1:45 · Demonstrate inclusion

Return to the explorer and use “Leer selección”. Focus the timeline with the keyboard and change a week. Mention the accessible table, 2D map and motion pause. Describe accessibility as a tested direction of work, not certified universal access.

## 1:45–2:00 · Show why the architecture can grow

Explain that the frontend, Python processing and audio development consume a shared versioned JSON contract. The existing tracks work immediately; full historical exports, national geographic clipping and the separately deployable Python service can progress independently. Close with the regional purpose: **help more people explore and understand satellite evidence through sight, sound and clear context.**

Before presenting: test with headphones on the actual device, check a WebGL-capable browser, verify the final deployment, and keep a local build available. Do not claim that hosting, live API ingestion, national clipping, all 2012–2026 tracks or blind-user validation have already been completed.
