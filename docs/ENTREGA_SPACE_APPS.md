## Project summary — draft in English

TerraEcho turns a real NASA Earth visualization into an interactive soundscape. Users can explore three curated readings of a GEOS Aerosols frame, isolate four visual layers, inspect the features behind each note, compare selections, and export an original sound with source metadata. Image height controls pitch, visual presence controls relative gain, and layer color selects timbre. A separate NASA FIRMS archive provides regional context for Peru using reproducible raw-point clipping and a documented retrospective baseline. Keyboard controls, textual features, mono playback and spoken descriptions support multiple ways to explore; participant validation is still pending.

## NASA data and method — draft

NASA SVS 5669 / GMAO GEOS Aerosols supplies the modeled frame dated August 19, 2025 at 20:00 UTC. We extract color masks and weighted visual features under an explicit image-space scan. These features do not measure atmospheric concentrations. NASA FIRMS VIIRS Suomi NPP Collection 2 Standard Processing country archives provide 2012–2025 thermal-activity observations. A separate recent-query mode supports NOAA-20/21 without pretending they share the historical baseline. Caldwell 73, credited to NASA/CXC/SYSTEM Sounds, inspired the use of visual features as musical parameters; TerraEcho creates its own synthesis rather than reusing that soundtrack.

## Impact and limitations — draft

The intended impact is to make Earth imagery inspectable through sound and to connect that exploration to a meaningful Peruvian context. We provide reproducible sources, downloadable audio and alternative controls. Automated contract, data-reconciliation, audio-buffer and accessibility checks are evidence of implementation, not proof of universal accessibility or learning benefit. Independent mask annotations and sessions with blind/low-vision users are the next evaluation gates. Hotspots are not individual forest fires, and the global EIC frame does not establish smoke caused by a selected Peru fire interval.
